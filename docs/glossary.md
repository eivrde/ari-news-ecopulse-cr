\# 📖 Glosario de Conceptos Técnicos  
\> \*\*ARI NEWS: EcoPulse CR\*\* — \*Inmersión ONE AI For Business (2026)\*

Este glosario reúne y documenta los conceptos clave en inteligencia artificial generativa, arquitectura de nodos, desarrollo front-end y diseño UI/UX integrados a lo largo del desarrollo del proyecto.

\---

\#\# 🤖 Conceptos de Inteligencia Artificial & Google Opal

\#\#\# 1\. Canvas / Workspace (Lienzo de Trabajo)  
Entorno visual interactivo de Google Opal donde se conectan nodos funcionalmente mediante diagramas de flujo para estructurar aplicaciones alimentadas por Inteligencia Artificial.

\#\#\# 2\. Grounded Search (Búsqueda Conectada / Fundamentada)  
Mecanismo de IA que conecta un modelo de lenguaje (LLM) con motores de búsqueda en tiempo real (Google Search) para extraer información veraz, actualizada y respaldada por fuentes verificables antes de generar una respuesta.

\#\#\# 3\. System Instructions & Guardrails (Instrucciones de Sistema)  
Reglas estrictas definidas a nivel de sistema dentro de los nodos de Opal para delimitar el comportamiento del modelo, imponer formatos de salida específicos (ej. HTML/CSS puro sin etiquetas envolventes) y evitar errores de CSP o comportamiento impredecible.

\#\#\# 4\. Multimodal Generation (Generación Multimodal)  
Capacidad de un sistema de IA para procesar, sintetizar y generar distintos tipos de medios (como texto plano, código estructurado e imágenes conceptuales) dentro de un mismo flujo de trabajo interconectado.

\#\#\# 5\. Snapshot / Publishing (Publicación Estática)  
Mecanismo en Google Opal para empaquetar una versión estable y congelada de un flujo de nodos y su interfaz renderizada, generando una URL pública estática que conserva su funcionamiento exacto sin sufrir alteraciones por futuras reejecuciones.

\#\# 🎨 Conceptos de Front-End & UI/UX

\#\#\# 6\. Scroll Snap (\`scroll-snap-type\`)  
Módulo de CSS3 que permite controlar la posición de desplazamiento de un contenedor con scroll. Garantiza que las tarjetas del carrusel se alineen magnéticamente al inicio o centro de la pantalla al finalizar el gesto de desplazamiento.

\#\#\# 7\. CSS Custom Properties / Tokens de Diseño  
Variables CSS (\`--bg-primary\`, \`--accent-color\`, etc.) definidas globalmente en la pseudo-clase \`:root\` que facilitan la tematización dinámica (Modo Claro / Modo Oscuro) y garantizan la consistencia estética en toda la interfaz.

\#\#\# 8\. URL Slugs & Formateo Seguro  
Proceso en JavaScript mediante el cual se limpian y transforman cadenas de texto (como el título de una noticia) eliminando acentos, caracteres especiales y convirtiendo espacios en guiones. Permite construir enlaces URL válidos y seguros para redirigir a búsquedas específicas en Google.

\#\#\# 9\. Webkit Scrollbar Styling (\`::-webkit-scrollbar\`)  
Pseudo-elementos de CSS que permiten personalizar la apariencia visual (ancho, color de fondo, bordes y tirador) de las barras de desplazamiento nativas del navegador para integrarlas orgánicamente con la paleta del sistema de diseño.

\#\#\# 10\. Responsive Web Design & Mobile-First  
Metodología de diseño y desarrollo donde la interfaz se concibe primeramente para dispositivos móviles pequeños, utilizando CSS Flexbox y \`@media queries\` para escalar progresivamente hacia pantallas de escritorio de gran formato.
